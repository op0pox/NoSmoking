# 웹 데모 (localhost 전용)

영상 분석 페이지와 실시간(웹캠) 페이지. 같은 PC의 브라우저에서만 열린다.
- 영상 분석: 영상은 분석하는 동안만 임시 파일로 두고 끝나면 바로 지운다.
- 실시간: 백엔드가 웹캠을 직접 읽는다. 화면 표시용 최신 프레임 한 장만 메모리에 두고 덮어쓴다.
- 어느 쪽도 프레임을 저장하지 않는다.

## 처음 한 번 설치

```bash
# 저장소 루트에서
NS-venv/bin/pip install fastapi "uvicorn[standard]" python-multipart
cd demo/frontend && npm install
```

## 실행 (터미널 2개)

```bash
# 1) 백엔드 — 저장소 루트에서
NS-venv/bin/uvicorn demo.backend.app:app --host 127.0.0.1 --port 8000

# 2) 프론트엔드 — demo/frontend에서
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 연다.

- 담배·연기 모델은 기본으로 저장소 루트의 `cigarette-v5-best.pt`를 쓴다.
  바꾸려면 백엔드 실행 전에 `NOSMOKING_CIGARETTE_MODEL=cigarette-v4-best.pt` 처럼 지정한다.
- 분석 결과는 백엔드 메모리에 최근 10개까지만 남는다(숫자만). 백엔드를 끄면 사라진다.
- **실시간 카메라 권한**은 백엔드를 실행한 터미널(또는 IDE)에 필요하다. 처음 [시작]을 누를 때
  macOS 권한 팝업이 뜨면 허용한다. 막았다면 시스템 설정 > 개인정보 보호 및 보안 > 카메라에서 켠다.
- 아이폰 연속성 카메라가 0번으로 잡히면 실시간 페이지에서 카메라 1번을 고른다.
- 실시간 카메라는 페이지를 떠나면 꺼지고, 화면을 보는 곳이 10초 동안 없으면 스스로 꺼진다.

## 네트워크 카메라(IP 카메라·CCTV) 연결

실시간 페이지의 **📡 네트워크 카메라 등록**에서 설치 위치 이름과 주소를 등록한 뒤, 카메라 목록에서 골라 시작한다.

- 주소 형식: IP 카메라·CCTV는 보통 `rtsp://아이디:비밀번호@192.168.0.30:554/stream1`(경로는 제조사마다 다름),
  폰 IP 카메라 앱은 보통 `http://192.168.0.23:8080/video`
- **같은 공유기 안의 주소(사설 IP)만 허용**한다. 영상이 인터넷의 외부 서버를 거치지 않게 하기 위함이다.
  영상을 회사 서버를 거쳐 보내는 클라우드 방식 카메라 앱은 쓰지 않는다
- 등록 정보는 `demo/backend/data/cameras.json`에 저장된다(커밋 안 함). 화면에는 비밀번호를 가려서 보여준다
- 최신 프레임만 읽어 지연이 쌓이지 않게 하고, 연결이 끊기면 5번까지 다시 연결해 본다. RTSP는 TCP로 받는다

### 실제 기기로 시험하는 순서
1. 노트북과 카메라(또는 폰)를 **같은 와이파이**에 연결한다. 학교 와이파이는 기기끼리 통신을 막는 경우가 많아,
   안 되면 폰 핫스팟이나 집 공유기로 시험한다
2. 폰이라면 IP 카메라 앱을 설치하고 앱이 보여주는 `http://192.168.…` 주소를 확인한다
3. **VLC**(미디어 > 네트워크 스트림 열기)에서 그 주소가 열리는지 먼저 확인한다. VLC에서 안 열리면 카메라·네트워크 문제다
4. 실시간 페이지에서 등록하고 [▶ 시작] → 판정 화면이 나오는지 확인한다
5. 카메라(앱)를 잠깐 껐다 켜서 "다시 연결하는 중…" 안내 뒤 화면이 돌아오는지 확인한다
- 실시간이 켜져 있는 동안에는 영상 분석을 할 수 없다(같은 모델·GPU를 쓰므로).

## 구성

| 경로 | 내용 |
|---|---|
| `backend/app.py` | FastAPI. `/api/status`, `/api/analyze`(업로드), `/api/analyze/{job_id}`(진행·결과), `/api/live/*`(실시간) |
| `backend/live.py` | 실시간 세션: 카메라 읽기 → 판정 → 화면 그리기(`edge/overlay.py`) → MJPEG |
| `backend/camera_source.py` | 입력 소스: 이 PC 카메라 / 네트워크 카메라(사설 IP 확인, 최신 프레임만, 자동 재연결) |
| `frontend/src/pages/` | 홈, 실시간, 영상 분석 |
| `frontend/src/components/Timeline.tsx` | 사람별 3단 타임라인 (손-입 거리 / 2차 확인 신뢰도 / 시간 필터 비율) |
| `frontend/src/api.ts` | 백엔드 응답 타입 (파이썬 dataclass와 필드 이름을 맞춘다) |

분석 로직은 평가 도구(`eval/`)와 같은 `edge/video_analysis.py`를 쓴다.
